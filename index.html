StyleMatch AI

AI-Powered Fashion Recommendation Application

Effective Date: 16 March 2026  ·  Version 1.0

✅ At a glance: StyleMatch AI does not store personal user data. Shoe images are processed in memory and discarded immediately after outfit generation. Pinterest boards are read only when you explicitly grant access and are never stored. No data is sold to third parties.

1. Introduction

StyleMatch AI ("we," "our," or "the Application") is an AI-powered fashion recommendation service that analyses a photograph of a shoe and returns a complete outfit recommendation. This Privacy Policy explains what information we collect, how we use it, and the choices available to you.

This policy applies to:

  • the StyleMatch AI web application at stylematch.ai
  • the developer API available at api.stylematch.ai
  • any third-party integrations you authorise, including Pinterest

This policy is written to satisfy the requirements of Pinterest's Developer API Terms of Service for applications that request read access to user boards.

3. How We Use Your Information

3.1 Core Functionality

All information collected is used solely to provide outfit recommendations. The processing pipeline is:

  1. Shoe image is received and passed to the CLIP vision model in memory
  2. Shoe attributes (type, colour, formality score) are extracted — the original image is discarded
  3. Outfit items are matched using vector similarity search against our fashion catalog
  4. If Pinterest is connected, your board data is analysed to refine style weighting
  5. The recommendation is returned to your browser and all intermediate data is discarded

3.2 Optional Style Profile Caching

With your explicit consent, we may cache a derived style profile (not your raw Pinterest data or images) to improve the accuracy of future recommendations. This cached profile contains:

  • A list of dominant style categories (e.g. "smart casual," "minimalist")
  • A colour palette summary (e.g. "earth tones," "monochrome")
  • A formality preference score on a 1–10 scale

This cached profile does NOT contain any Pinterest pin images, board names, personal identifiers, or your shoe photographs.

Cached profiles are stored for a maximum of 30 days and can be deleted at any time by revoking Pinterest access through your Pinterest account settings or contacting us at privacy@stylematch.ai.

3.3 Blockchain Ledger (OutfitLedgerTool)

If the blockchain ledger feature is enabled, an anonymised record of each approved outfit recommendation is written to the Hedera Consensus Service. This record contains:

  • An anonymous outfit identifier (not linked to your name, email, or device)
  • A pseudonymous session user ID (a random string, not your Pinterest username)
  • The shoe type and style category
  • The list of recommended outfit item names
  • A UTC timestamp
🔒 Immutability notice: Records written to the Hedera Consensus Service are permanent and cannot be deleted. We therefore write only anonymised, non-personal data. No information that could directly identify you is included in ledger records.

5. Pinterest-Specific Disclosures

This section is required by the Pinterest API Terms of Service and addresses Pinterest's developer policy requirements directly.

5.1 Data Use Restrictions

In compliance with Pinterest's Developer API Terms, we confirm that Pinterest user data accessed through the API:

  • Is used only for the purpose described to the user at the time of authorisation (fashion recommendation)
  • Is not used for advertising targeting or to build advertising profiles
  • Is not sold, licensed, or transferred to third parties except as listed in Section 4
  • Is not used to train machine learning models
  • Is not used to create derivative datasets
  • Is not combined with other personal data sources to build profiles beyond what is needed for outfit recommendations

5.2 Scope of Access

The Application requests the minimum Pinterest OAuth scopes necessary to provide its functionality. We do not request write access, social graph access, or access to follower data. All access is read-only.

5.3 Revoking Pinterest Access

You can revoke the Application's access to your Pinterest account at any time by:

  • Visiting pinterest.com → Settings → Security → Apps with access → StyleMatch AI → Revoke
  • Emailing privacy@stylematch.ai with the subject line "Revoke Pinterest Access"

Upon revocation, we will delete any cached style profile derived from your Pinterest data within 48 hours.

5.4 Pinterest as Data Controller

Pinterest, Inc. is an independent data controller for data you share with Pinterest directly. This Privacy Policy does not govern Pinterest's use of your data. Please review Pinterest's Privacy Policy at pinterest.com/about/privacy for information about how Pinterest handles your data.

7. Your Rights

Depending on your location, you may have rights under applicable data protection laws including the GDPR (EU/UK), CCPA (California), NDPR (Nigeria), and others. Because we collect minimal personal data, most requests will result in confirmation that we hold no data about you.

7.1 Rights Available to All Users

  • Right to know — you can ask what data we hold about you
  • Right to deletion — you can request deletion of your style profile (if cached)
  • Right to opt out — you can disable Pinterest integration and style profile caching at any time
  • Right not to be subject to automated decisions with legal effect — outfit recommendations are non-binding and purely informational

7.2 EU/UK GDPR Specific Rights

  • Right to access (Article 15) — request a copy of any personal data we hold
  • Right to rectification (Article 16) — correct inaccurate data
  • Right to erasure (Article 17) — request deletion of personal data
  • Right to restriction of processing (Article 18)
  • Right to data portability (Article 20) — receive your style profile in machine-readable format
  • Right to object (Article 21)

Our lawful basis for processing is: (a) contractual necessity (providing the recommendation service you requested) and (b) legitimate interests (service reliability and security). We do not rely on consent as a lawful basis except for optional style profile caching.

To exercise any of these rights, contact privacy@stylematch.ai. We will respond within 30 days.

8. Security

We implement appropriate technical and organisational measures to protect data in transit and at rest:

  • All API endpoints are served over HTTPS/TLS 1.3
  • API keys and credentials are stored as environment variables, never in source code
  • Database access is restricted to the application server via private network
  • Session tokens are short-lived (2 hours) and stored only in server-side Redis
  • The application does not use cookies for tracking; a session token is stored in memory only during your active session

No method of transmission over the internet or method of electronic storage is 100% secure. We will notify affected users within 72 hours of becoming aware of a data breach that affects personal data.

9. Children's Privacy

The Application is not directed at children under the age of 13 (or 16 in the EU). We do not knowingly collect personal information from children. If you believe a child has provided us with personal information, please contact privacy@stylematch.ai and we will promptly delete it.
