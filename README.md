## How to host this on GitHub Pages (5 steps)

**Step 1 — Create a new GitHub repository**
- Go to [github.com/new](https://github.com/new)
- Name it: `stylematch-privacy-policy`
- Set it to **Public**
- Click **Create repository**

**Step 2 — Upload the file**
- Click **Add file → Upload files**
- Drag `index.html` into the upload area
- Click **Commit changes**

**Step 3 — Enable GitHub Pages**
- Go to **Settings → Pages**
- Under **Source**, select **Deploy from a branch**
- Set Branch to `main`, folder to `/ (root)`
- Click **Save**

**Step 4 — Wait ~60 seconds, then visit your live URL**
```
https://<your-github-username>.github.io/stylematch-privacy-policy/
```

**Step 5 — Link to it from your app**

In your frontend `index.html`, add a link wherever you reference the privacy policy:
```html
<a href="https://<your-username>.github.io/stylematch-privacy-policy/">
  Privacy Policy
</a>
```

---

## Updating the policy

1. Edit `index.html` directly on GitHub (click the file → pencil icon)
2. Update the effective date near the top of the file
3. Commit — GitHub Pages redeploys automatically in ~60 seconds
